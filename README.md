## ✨ 裝了之後有什麼不一樣？

### 🀄 整個遊戲變中文

- **劇情、對話、選單、戰鬥訊息全部翻成繁體中文**，總共約 4 萬句遊戲文字。
- 寶可夢、招式、道具、特性的名稱用**官方繁中譯名**（例如「皮卡丘」「十萬伏特」「精靈球」），跟正版遊戲一樣，不用重新認名字。
- 原版遊戲**根本顯示不了中文**（會變方塊、字跑出框外）。補丁加了清楚的中文字型（Noto Sans CJK），並修好中文換行、選單裁切、戰鬥畫面文字重疊等問題。
- 戰鬥按鈕的圖片也換成中文。

### 🧭 不再迷路、不再漏東西

- **「主線任務」**：按暫停選單就能看到「下一步要去哪、做什麼」，城鎮地圖上也會用紅色「!」標出地點。整個劇情 436 步都有提示。
- **隱藏道具會閃光**：地上看不見的道具會定時閃一下，不用再對著每一格狂按確認。
- **會送東西的 NPC 頭上有「!」**：一眼就知道誰有道具可以拿，路上願意跟你走的寶可夢也會標出來。

### ⚔️ 戰鬥資訊一目了然

- **招式按鈕旁邊直接顯示相剋**：紅圈＝效果絕佳、空心圈＝普通、藍三角＝效果不好、灰叉＝沒有效果。不用背屬性表。
- **戰鬥選單直接列出招式的屬性、物理／特殊、威力、命中、PP**。
- **能力階級顯示**：寶可夢的攻擊、速度等被提升或降低時，血條下方會出現「+2」「−1」這樣的小標籤。
- 能力畫面的招式列表會標出物理／特殊／變化。

### 🛠️ 寶可夢修改器（想怎麼玩都行）

在隊伍裡選一隻寶可夢 →「**修改數據**」，就能用中文選單：

- 個體值（IV）一鍵全滿、努力值（EV）一鍵全滿
- 換特性（含隱藏特性）、換性格、改等級、變成異色（色違）
- 教任何招式（招式列表是中文，並顯示招式資料）、所有招式 PP 一鍵提升到最大

### ⚖️ 玩法調整（會改變原版平衡）

- **遇到野生寶可夢的頻率減半**：走草叢不會三步一戰。
- **速度影響命中**：比對手快，招式比較容易打中；比對手慢，就比較容易被閃掉。
- **等級曲線更連續**：離開關都之後，野生與訓練家的等級會配合你的劇情進度，不會帶著高等隊伍一直打個位數的寶可夢。
- **野外有機會遇到神獸**：草叢、洞窟、水上等地方有 2% 機率遇到該地區你還沒抓到的神獸。

> [!NOTE]
> 這是一整包一起安裝，**不能只挑其中幾項**。介意玩法調整的話，請先考慮清楚再安裝。

## 📖 安裝教學（照著做就好）

**需要：** Windows 10 或 Windows 11（64 位元）。第一次安裝要**連上網路**，因為補丁會自動下載中文字型（約 16 MB）。

### 第 1 步：下載遊戲並解壓縮

1. 用上面的 [MEGA](https://mega.nz/file/F2QV2aSR#lRU_hYarsqe5ehE7YpkkNV3oSJAVzOPNAxsDzmVy00A) 或 [Google Drive](https://drive.google.com/file/d/1SYyhsfPQLyeSCDZd1tnNOqzunGLEafwu/view?usp=drive_link) 連結下載遊戲壓縮檔。
2. 在下載好的壓縮檔上按**滑鼠右鍵 →「全部解壓縮」**。如果是 `.rar` 或 `.7z` 檔，Windows 打不開的話，請先安裝免費的 [7-Zip](https://www.7-zip.org/)，再按右鍵 → 7-Zip → 解壓縮。
3. 一定要**完整解壓縮**，不要直接在壓縮檔裡面開遊戲。
4. 解壓縮後打開資料夾，找到 **`Game.exe`**。**記住這個資料夾在哪裡**，等一下要用。

> [!TIP]
> 遊戲資料夾建議放在 `D:\Games\` 這類自己建立的資料夾，**不要放在 `C:\Program Files`**，那裡常常會因為權限問題裝不上去。

### 第 2 步：下載中文化補丁

點這裡下載 👉 **[FireAsh-zhTW-3.7-extras.2.exe](https://github.com/NiceJobGuys/FireAsh-Translate-zh-TW/releases/download/v3.7-extras.2/FireAsh-zhTW-3.7-extras.2.exe)**

不用註冊或登入 GitHub。小技巧：**把這個 EXE 放進有 `Game.exe` 的遊戲資料夾裡**，等一下它會自動找到遊戲，連資料夾都不用選。

### 第 3 步：確認遊戲已經關閉

如果遊戲開著，請先**正常存檔並關閉遊戲**。

### 第 4 步：執行補丁

1. 雙擊 `FireAsh-zhTW-3.7-extras.2.exe`。
2. 如果跳出藍色的「**Windows 已保護您的電腦**」視窗：按「**其他資訊**」→「**仍要執行**」。
   （這是因為補丁沒有付費購買數位簽章，並不是中毒。不放心的話，請看[常見問題](#-常見問題)裡的檢查方法。）

### 第 5 步：選擇遊戲資料夾

在補丁視窗裡選擇**裡面有 `Game.exe` 的那個資料夾**。如果 EXE 本來就放在遊戲資料夾，路徑會自動填好。

### 第 6 步：按「安裝全部功能」

按下去之後等它跑完（會自動下載字型、備份原檔、安裝），看到「**安裝完成！**」就好了。

### 第 7 步：開遊戲，切換成中文

1. 打開遊戲資料夾裡的 `Game.exe`。
2. 進入遊戲後按選單鍵打開暫停選單，選 **Options**（設定）。如果還在開頭的「Continue／New Game」選單，那裡也有 **Options**。
3. 在 Options 裡找到 **Language**，把它改成「**繁體中文**」。

🎉 完成！之後開遊戲就是中文。原本的存檔可以直接繼續玩。

## ❓ 常見問題

<details>
<summary><b>補丁說「版本不符」或「不支援」，不肯安裝</b></summary>

補丁會先檢查遊戲檔案，確認是它認得的版本才安裝，避免把遊戲弄壞。遇到這個訊息通常是：

- 遊戲版本不是 3.7／3.7.1，或是官方換過壓縮檔內容。
- 遊戲裝過別的 MOD 或別的中文化。
- 沒有完整解壓縮。

請重新下載官方完整版、解壓縮到**新的空資料夾**，再裝一次。還是不行的話，請到 [Issues](https://github.com/NiceJobGuys/FireAsh-Translate-zh-TW/issues) 回報，附上補丁顯示的訊息。
</details>

<details>
<summary><b>補丁說某個檔案是「唯讀」</b></summary>

在補丁指出的那個檔案上按右鍵 →「內容」→ 把下方的「**唯讀**」取消打勾 →「確定」，然後再按一次安裝。
</details>

<details>
<summary><b>會不會弄壞我的存檔？</b></summary>

不會。補丁不碰存檔，安裝前也會先把要換掉的遊戲檔備份到遊戲資料夾裡的 `FireAsh-Extras-backup`。
</details>

<details>
<summary><b>怎麼確認 EXE 沒被動過手腳？</b></summary>

[發布頁](https://github.com/NiceJobGuys/FireAsh-Translate-zh-TW/releases/tag/v3.7-extras.2)有 `.sha256` 檔。在下載資料夾按右鍵 →「在終端機中開啟」，輸入：

```powershell
Get-FileHash .\FireAsh-zhTW-3.7-extras.2.exe
```

顯示的那串英數字跟 `.sha256` 檔裡的一樣，就是原版檔案。不需要關閉防毒軟體。
</details>

<details>
<summary><b>想換回英文</b></summary>

不用移除補丁，到 Options（設定）的 Language 改回 English 就好。
</details>

## ↩️ 還原（移除補丁）

1. 關閉遊戲。
2. 再執行一次 `FireAsh-zhTW-3.7-extras.2.exe`，選同一個遊戲資料夾。
3. 按「**還原**」。

遊戲就會回到安裝前的樣子，存檔不變。注意：**還原前不要搬動遊戲資料夾**，要放回安裝時的位置才找得到備份。

## 🔄 之後有新版本怎麼辦？

新版補丁會放在[發布頁](https://github.com/NiceJobGuys/FireAsh-Translate-zh-TW/releases)。官方遊戲更新後，舊補丁可能會拒絕安裝（這是保護機制）。請等本專案出新版，不要硬裝。

## 原始碼與翻譯

以下是給想研究或協助維護的人看的，玩家可以略過。

- **翻譯基準**：遊戲資料夾 3.7（內附 Changelog 3.7.1，程式內部版本 3.7.0），以檔案 SHA-256 判斷版本，見 `source-manifest.json`。
- **翻譯數量**：原訊息表 40,775／42,534 個文字位置已翻譯，其餘 1,759 個是刻意保留的人名、暱稱、縮寫、程式識別碼；另補上 1,207 筆實際執行時才出現的文字、214 種 NPC 寶可夢暱稱與不經語言檔的直接顯示文字。各區段統計見 `coverage.json`。
- **翻譯來源**：寶可夢、招式、道具、特性名稱取自 [PokeAPI](https://github.com/PokeAPI/pokeapi) 的官方繁中資料，其餘由 AI（Codex、Claude）翻譯並校對，未使用付費翻譯 API。
- **主要檔案**：
  - `translation-source/`：從遊戲匯出的英文原文。
  - `translations/`：繁中譯文、人工對照與刻意保留清單。
  - `glossary.json`：人名、地名與專有名詞對照。
  - `tools/`：匯出、建置、驗證與安裝工具。
  - `tools/installer/`：玩家用的 EXE 安裝程式原始碼，[安裝程式技術說明](tools/installer/README.md)。
  - `*-fix.md`：各次修正的詳細紀錄。
- **維護文件**：[MAINTAINING.md](MAINTAINING.md)（翻譯批次格式與重建步驟）、[TECHNICAL.md](TECHNICAL.md)（完整檔案用途、建置指令、字型選擇與歷次修正紀錄）。

## 驗證與已知限制

- **尚未完成整個遊戲的實機遊玩驗收**。文字與畫面已用遊戲本身的 Ruby 引擎做過大量自動測試，安裝程式也實際跑過安裝、重複安裝、還原、唯讀檔與中文路徑；但這些測試不等於把遊戲從頭玩到尾。
- 只在 Windows 11 64 位元測試過，沒有在乾淨的 Windows 10 上測試。
- 補丁是以作者本機的 3.7 版遊戲檔案製作，**沒有拿現在官網重新下載的壓縮檔驗證過**。如果官方換過檔案，補丁會拒絕安裝而不會硬裝，請到 Issues 回報。
- 遊戲裡少數畫在圖片上的英文還沒翻；部分劇情提示（阿羅拉、伽勒爾段）比較簡略。
- 「主線任務」與「!」提示是依遊戲資料推算，偶爾會有「有東西可拿但條件還沒達成」的情況。
- 有問題歡迎到 [Issues](https://github.com/NiceJobGuys/FireAsh-Translate-zh-TW/issues) 回報。
